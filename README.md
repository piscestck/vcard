# Free Digital vCard Website

This is a zero-cost starter digital business-card website designed for GitHub Pages.

## Files
- `index.html` – card layout
- `style.css` – mobile-friendly design
- `config.js` – change your contact details here
- `app.js` – Save Contact, Share, and QR functions
- `assets/logo.svg` – replace with your logo
- `assets/profile.svg` – replace with a profile photo

## Quick setup
1. Create a free GitHub account.
2. Create a new public repository, e.g. `vcard`.
3. Upload all files in this folder.
4. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
5. Wait for deployment.
6. Open the GitHub Pages URL.
7. Edit `config.js` and replace the sample details.

## Important
The QR button generates a QR code for the current page URL. The Save Contact button creates a standard `.vcf` contact file in the browser.

For a custom company domain later, connect the domain to GitHub Pages and keep the same card URLs.

## Multiple employees
For a simple free setup, duplicate `index.html`, `config.js`, and `app.js` into separate folders, or later upgrade to a single data-driven application.
